Чтобы приложение JAVA FX запускалось у пользователей:
Нужно использовать пакет установщика.


-----
Быстрое обходное решение для проверки работоспособности JAR:
1. Установаить Open JDK моей версии 21.0.9  (мой OpenJDK21U-jdk_x64_windows_hotspot_21.0.9_10.msi)
2. Распаковать openjfx моей версии 21.0.9   (лежит в репозитории openjfx-21.0.9_windows-x64_bin-sdk.zip)
3. Подкинуть JAR файл - который получается запуском "mvn package" (в Intelliji IDEA)
4. Запускать start.bat
Внутри start.bat указан путь к java.exe - его можно узнать командой  `where java`
если на компе одна версия java, путь можно заменить просто на 'java'
а также вместо --module-path "javafx-sdk-21.0.9\lib"  указать свой (куда распакуете openjfx-21.0.9_windows-x64_bin-sdk.zip).
