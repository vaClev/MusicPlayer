1. Для установки пакета 
sudo dpkg -i "путь к deb пакету"

Например:
```bash
sudo dpkg -i output/musicpro_1.0_amd64.deb
```

2. После установки приложение создаст файлик `musicplayer.properties` со стандартными настройками.
ip адрес для подключения к серверу нужно прописать свой. 

Файл скопировать в   
```bash
~/test/MusicPlayer
либо
~/test/
```
* в Linux идеологически неправильно хранить файл properties в /opt/
При запуске с ярлыка с обычными правами приложение не мжет читать файл в папке /opt/
