------------------------------------
Если есть проблемы с подключением.
Открыть папку в которую установлено, по умолчанию -C:\Program Files\MusicPro1

файл - musicplayer.properties
server.url=http\://127.0.0.1\:5098/

вместо 127.0.0.1 - указывать реальный ip сервера.
Получится например
server.url=http\://192.168.3.122\:5098/

Перезапустить приложение
